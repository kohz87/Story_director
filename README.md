# Story Director

A SillyTavern extension that keeps a story's world moving consistently: it tracks off-screen
agendas, world events, hooks, clocks and travel, checks dates and distances in code, injects
a short note before every reply, and plans each story arc with a model you choose.

Works with [Story Block](https://github.com/kohz87/Story_block).

**Status:** design. Read [docs/DESIGN.md](docs/DESIGN.md); no code yet.
